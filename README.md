# Korval — landing (koncept)

Лендинг вымышленного финтех-сервиса Korval в швейцарском стиле. Портфолио-кейс: макет в Figma → код.

Чистые HTML, CSS и JS — без сборщика и зависимостей.

## Структура

```
index.html            разметка всех секций, меню и модалки «Umów demo»
assets/css/styles.css стили: десктоп 1440 → ноутбук (пропорционально), мобайл < 860px
assets/js/main.js     плавный скролл, меню, форма, появление блоков
assets/favicon.svg
```

## Запуск локально

Откройте `index.html` в браузере или поднимите простой сервер:

```bash
npx serve .
# или
python3 -m http.server 8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в корень все файлы из этой папки.
2. Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Что работает

| Элемент | Поведение |
|---|---|
| Навигация, ссылки футера, «Przewiń ↓», пункты меню | Плавный скролл к разделу (своя анимация, easeInOutCubic). Адрес обновляется, кнопка «Назад» работает |
| «Menu» | Полноэкранное меню выезжает сверху, пункты появляются по очереди. Закрывается по «Zamknij» и Esc |
| «Umów demo», кнопки тарифов | Модальное окно с формой. Тариф подставляется автоматически |
| Форма | Проверка полей (обязательные, формат e-mail), экран «Dziękujemy» |
| Секции | Плавное появление при прокрутке |

Анимации отключаются, если в системе включено «Уменьшить движение» (`prefers-reduced-motion`).

## Что нужно доделать перед реальным использованием

- **Отправка формы.** Сейчас данные никуда не уходят. В `assets/js/main.js` есть закомментированный пример для [Formspree](https://formspree.io): создайте форму, подставьте свой ID и раскомментируйте `fetch`.
- **Заглушки.** Ссылки с атрибутом `data-placeholder` (X, Discord, GitHub, Kariera, «Zobacz dokumentację», политика и регламент) никуда не ведут — замените `href="#"` на реальные адреса.
- **Шрифты** грузятся с Google Fonts (Inter, Roboto Mono).

## Сетка

- Десктоп: 12 колонок, поля 40, межколонник 24 (при 1440px). Ниже 1440 всё масштабируется через переменную `--u`.
- Мобайл (< 860px): 4 колонки, поля 20, межколонник 16. Первая колонка — служебный «рельс» для подписей, контент со 2-й колонки.
